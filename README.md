# 기수정렬 버킷 퍼즐

LSD 기수정렬(radix sort)을 직접 손으로 해보는 웹 퍼즐 게임.
번호표를 든 캐릭터들을 0~9번 방에 나눠 넣고 다시 줄 세우며 정렬한다. 기수 반장이 진행을 도와주고, 레벨마다 급식실·놀이공원·우주선 같은 스토리가 있다.

플레이: https://billyux.github.io/aaa/

- 맨 앞 카드의 현재 자리(1의 자리 → 10의 자리 → …) 숫자에 맞는 0~9 버킷을 클릭하거나 키보드 숫자키를 누른다.
- 카드를 다 넣으면 **버킷 모으기**(Space)로 0번 버킷부터 순서대로 모은다.
- 모든 자리를 끝내면 정렬 완성. 레벨이 오를수록 카드 수와 자릿수가 늘고, 일부 레벨은 자리 힌트가 꺼진다.
